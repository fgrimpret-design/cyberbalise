Analysez un message suspect

Renseignez l'expéditeur et le texte d'un SMS ou d'un e-mail, ou importez une capture d'écran : en quelques secondes, découvrez les signaux d'arnaque et ce qu'il faut faire. Gratuit, sans inscription.

Analyse en cours : rien ne quitte votre appareil.

Vous pouvez aussi glisser-déposer un fichier dans ce cadre ou coller une image avec Ctrl+V. Image PNG, JPG ou WebP ou fichier .txt, 10 Mo maximum. Après une capture, relisez et corrigez le texte : la lecture d'une image peut se tromper (chiffres, lettres, liens).
Si votre texte se termine par des mentions légales ou un lien de désinscription, l'outil les repère aussi tout seul.

Pas de message sous la main ? Testez l'outil avec un exemple : ce sont des messages fictifs écrits par CyberBalise (trois arnaques courantes et un message normal pour comparer).

Comment ça marche. Choisissez d'abord si vous analysez un SMS ou un e-mail. Renseignez ensuite l'expéditeur (adresse e-mail ou numéro du SMS), l'objet et le pied de page de l'e-mail si vous les avez, puis fournissez le texte du message : en important une capture d'écran ou un fichier texte (.txt), ou en le collant. Relisez le texte importé, puis lancez l'analyse. L'outil repère les signaux classiques d'une arnaque et vous dit quoi faire. L'analyse se fait dans votre navigateur : le fichier et le message ne sont pas envoyés à un serveur d'analyse. Pour lire une capture, le navigateur télécharge un module de reconnaissance de caractères depuis un serveur public, sans y envoyer votre image.

Ce que l'outil peut et ne peut pas faire

  • Il repère des signaux fréquents dans les arnaques : urgence, menace, demande de code ou de paiement, lien suspect, usurpation d'un organisme connu, faux proche, chantage…
  • Il examine aussi l'expéditeur, l'objet et le pied de page si vous les renseignez : adresse ou numéro d'expéditeur qui imite un organisme, objet alarmiste ou en majuscules, pied de page sans identité ni désinscription, liens piégés. Ce sont des indices, pas des preuves : un expéditeur usurpé de façon parfaite ne peut pas être détecté.
  • Il ne vérifie pas les liens en ligne et ne consulte aucune base de données : il ne peut pas garantir qu'un message est sans danger. Un message sans signal peut quand même être une arnaque.
  • La lecture des captures peut faire des erreurs sur les images floues ou petites : relisez le texte extrait avant l'analyse.
  • Dans le doute, la règle reste la même : n'agissez jamais depuis le message reçu. Ouvrez vous-même le site ou l'application de l'organisme, ou appelez-le au numéro habituel.
