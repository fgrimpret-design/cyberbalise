Comment ça marche. Collez le texte d'un SMS, d'un e-mail ou d'un message, ou déposez une capture d'écran : l'outil repère les signaux classiques d'une arnaque et vous dit quoi faire. L'analyse se fait dans votre navigateur : le message et l'image ne sont envoyés à personne. Pour lire le texte d'une capture, le navigateur télécharge une fois un module de reconnaissance de caractères depuis un serveur public, sans y envoyer votre image.

Ce que l'outil peut et ne peut pas faire

  • Il repère des signaux fréquents dans les arnaques : urgence, menace, demande de code ou de paiement, lien suspect, usurpation d'un organisme connu, faux proche, chantage…
  • Il ne vérifie pas les liens en ligne et ne consulte aucune base de données : il ne peut pas garantir qu'un message est sans danger. Un message sans signal peut quand même être une arnaque.
  • La lecture des captures peut faire des erreurs sur les images floues ou petites : relisez le texte extrait avant l'analyse.
  • Dans le doute, la règle reste la même : n'agissez jamais depuis le message reçu. Ouvrez vous-même le site ou l'application de l'organisme, ou appelez-le au numéro habituel.
